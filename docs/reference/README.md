# Reference

Descrição técnica da máquina. Consulte quando souber o que quer e precisar do detalhe exato: o nome do campo, o default, o código de status, o label da métrica.

Verificado contra o binário da Fase 1.

- [Configuração](configuration.md) — todo campo do YAML, com tipo, default e regra de validação.
- [Erros](errors.md) — códigos de status, corpo de erro e o que cada situação produz.
- [Headers](headers.md) — o que o gateway remove, reescreve e injeta, em cada sentido.
- [Observabilidade](observability.md) — endpoints administrativos e métricas com seus labels.

Para entender **por que** o gateway é assim, veja [Explanation](../explanation/). Para resolver uma tarefa concreta, veja [How-to](../how-to/).
